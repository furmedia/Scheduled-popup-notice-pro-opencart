# Scheduled Popup & Notice Pro

## Short description

Schedule polished storefront popups and optional order-confirmation messages in OpenCart 3.x. Set a start date, an exclusive expiry date, timezone, editable copy, and a responsive popup design from admin.

## Full description

Scheduled Popup & Notice Pro helps store owners communicate temporary announcements without editing theme files or remembering to remove banners manually. Configure the message once, choose when it starts, and the extension automatically stops displaying it after the expiry time.

The popup is centered, responsive, keyboard-friendly, and includes a visible close button, overlay, optional blur effect, lazy-loaded artwork, and session dismissal. The optional email message is added only while the schedule is active, so normal order emails return automatically after expiration.

## Highlights

- Date/time scheduling with timezone validation.
- Exclusive expiration logic for precise campaign windows.
- Editable popup title, main message, submessage, and email message.
- Responsive desktop and mobile layout.
- Safe cache action that preserves carts, sessions, orders, and customers.
- OpenCart admin translations: English, Romanian, German, Spanish, French, Italian, and Brazilian Portuguese.
- No external libraries or recurring service required.

## Requirements

- OpenCart 3.0.x.
- PHP 7.4 or newer.
- OCMOD enabled.

## Included files

- OpenCart OCMOD installer package.
- Installation and configuration manual.
- Marketplace banner artwork in 710x380 JPG format.
- Source files for review and support.

## Support scope

Support covers installation, OCMOD refresh, module permissions, scheduling, translations, popup display, and email integration. Theme-specific modifications may require compatibility work when a theme replaces the standard OpenCart footer pipeline.
