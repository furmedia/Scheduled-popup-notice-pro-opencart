# Scheduled Popup Notice Pro for OpenCart 4

Native OpenCart 4 package. The extension uses OpenCart events for the storefront popup and for adding the scheduled message to new-order email comments. It does not modify core files or theme templates.

Install the `.ocmod.zip` from **Extensions > Installer**, then install the module from **Extensions > Extensions > Modules**. The first save registers the events again, so it is safe to change settings later.
